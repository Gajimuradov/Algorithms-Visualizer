# Algorithms Visualizer

React + TypeScript тренажер для визуализации базовых алгоритмов и структур данных. Проект рассчитан на резюме, подготовку к стажировкам и объяснение алгоритмов через состояние, подсветку активных элементов и короткий текст текущего шага.

## Возможности

- каталог алгоритмов на главной странице с Big-O и ключевыми темами;
- единое управление для каждого сценария: `Start`, `Pause`, `Step`, `Reset`;
- редактируемые входные данные для массивов, стека, очереди и графа;
- SVG-визуализация активных указателей, сравнений, swap, visited nodes и traversal order;
- текстовое объяснение каждого состояния;
- прогресс выполнения текущего сценария;
- алгоритмическая логика отделена от React-компонентов;
- unit tests покрывают базовые сценарии и edge cases.

## Алгоритмы

- `Binary Search` - отсортированный массив, `left / mid / right`, поиск `target`;
- `Selection Sort` - поиск минимума, сравнения, swap и итоговый массив;
- `Stack` - операции `push` и `pop`, модель LIFO;
- `Queue` - операции `enqueue` и `dequeue`, модель FIFO;
- `BFS` - обход графа слоями через queue;
- `DFS` - обход графа в глубину через stack.

## UX-решения

- главная страница сразу показывает продуктовый контекст: что тренируется, сколько алгоритмов и как выглядит шаг визуализации;
- карточки алгоритмов сканируются по номеру, названию, сложности и тегам;
- экран алгоритма разделен на входные данные, управление, визуализацию и объяснение шага;
- прогресс-бар помогает понимать, где пользователь находится внутри сценария;
- интерфейс использует CSS Modules и не зависит от тяжелых UI-библиотек.

## Структура

```text
src/algorithms       чистые step-based функции и тесты
src/components       общие UI-компоненты и SVG-визуализации
src/pages            экраны алгоритмов
src/hooks            управление проигрыванием шагов
src/utils            парсинг пользовательского input
src/data             описания алгоритмов и Big-O
```

## Что демонстрирует проект

- декомпозицию UI и алгоритмической логики;
- generator / step-based подход;
- типизацию состояний алгоритмов;
- SVG-визуализацию без тяжелых UI-библиотек;
- UX для учебного инструмента;
- unit tests для обычных сценариев и edge cases: пустой input, дубликаты, некорректные операции.
