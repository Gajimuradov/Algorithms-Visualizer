# Algorithms Visualizer

React + TypeScript pet-проект для визуализации базовых алгоритмов и структур данных. Проект сделан для резюме, подготовки к стажировкам и тренировки понимания пошагового выполнения алгоритмов.

## Что делает проект

- показывает список алгоритмов на главной странице;
- для каждого алгоритма выводит идею, Big-O по времени и памяти;
- принимает входные данные;
- поддерживает управление `Start`, `Pause`, `Step`, `Reset`;
- подсвечивает активные элементы на текущем шаге;
- объясняет текущий шаг текстом;
- хранит алгоритмическую логику отдельно от React UI.

## Реализованные алгоритмы

- `Binary Search` - отсортированный массив, `left / mid / right`, `target`;
- `Selection Sort` - сравнения, поиск минимума, swap, итоговый массив;
- `Stack` - операции `push` и `pop`, принцип LIFO;
- `Queue` - операции `enqueue` и `dequeue`, принцип FIFO;
- `BFS` - обход графа в ширину, queue, visited nodes;
- `DFS` - обход графа в глубину, stack, visited nodes.

## Как запускать

```bash
npm install
npm run dev
```

Проверки:

```bash
npm run test
npm run build
```

## Какие навыки демонстрирует

- декомпозиция UI и бизнес-логики;
- generator / step-based подход к алгоритмам;
- типизация состояний алгоритмов;
- визуализация данных через SVG;
- базовые unit tests для чистых функций;
- работа с React hooks и CSS Modules без тяжелых UI-библиотек.

## Что можно улучшить

- добавить routing и deep links на конкретный алгоритм;
- сохранить пользовательские входные данные в `localStorage`;
- добавить больше алгоритмов: merge sort, quick sort, Dijkstra, heap;
- сделать экспорт шагов в JSON;
- добавить Canvas-режим для больших графов и массивов;
- расширить тесты edge cases: пустые массивы, дубликаты, некорректный input.
